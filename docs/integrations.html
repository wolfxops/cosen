Integrations catalog

Use Cosen with every LLM CLI and SDK your developers already have, then export cost, observability, and security into OWASP reports, SonarQube, GitHub Code Scanning, Prometheus, Grafana, and OpenTelemetry. 

# discover + apply
cosen integrate list
cosen integrate show openai-python
cosen integrate show sonarqube
cosen export sarif --hours 24 --out reports/cosen-security.sarif
cosen export owasp --hours 24 --out reports/cosen-owasp.json

Application SDKs

Drop-in base_url / api_base — no vendor lock-in inside Cosen.

  • OpenAI Python / Node — examples/openai_sdk.py, examples/openai_sdk.mjs
  • Anthropic Python — Messages API via examples/anthropic_sdk.py
  • LangChain — ChatOpenAI(base_url=…)
  • LlamaIndex — OpenAILike(api_base=…)

Tag every call with X-COS-Feature and X-COS-Project so spend and blocks roll up by product feature.

OWASP mapping (runtime)

  • LLM01 Prompt Injection — prompt_injection, jailbreak
  • LLM02 Sensitive Information Disclosure — secrets, pii, system_leak
  • LLM05 Improper Output Handling — output scan + redact/block
  • LLM07 System Prompt Leakage — system_leak
  • LLM10 Unbounded Consumption — daily feature/project USD budgets

Categories without an on-path signal (supply chain, poisoning, misinformation, …) are reported as gaps with companion-tool guidance (Semgrep, Trivy, eval harnesses).
