One suite, three critical jobs

Stop running disconnected tools. Cosen puts cost, observability, and security on the exact same request path.

Cost & Budgets

Track token usage × model price, tagged by feature, project, and user. Set daily kill-switches to prevent runaway agents from burning your budget.

Observability

Zero-instrumentation tracing. View model mix, latency, and spend by feature in a local web dashboard or via CLI reports. No SaaS account required.

On-Path Security

Deterministic scanners intercept requests and responses. Block or redact secrets, PII, prompt injections, and system-prompt leaks instantly.

Drop-in Replacement

Cosen speaks native OpenAI and Anthropic protocols. Just change your Base URL and add custom attribution headers.

  • Model-agnostic: No vendor SDK lock-in.
  • Local-first: SQLite on disk, no mandatory cloud.
  • Product attribution: Tag calls with X-COS-Feature.

Ready to self-host?

# Clone and install git clone https://github.com/cosen-ai/cosen.git cd cosen python -m pip install -e . # Initialize policy and seed demo data cosen init cosen demo # Start the gateway + web UI cosen serve --mock
