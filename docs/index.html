One suite, three jobs

Most teams run three disconnected tools. Cosen runs them on the same request path so your data model stays consistent.

Cost Feature-level spend

Token usage × model price, tagged by feature, project, and user. Set daily kill-switches before a runaway agent burns the budget.

Observability Traces & latency

SQLite-backed trace store, local web dashboard, and CLI reports. See model mix, latency, and spend by feature without a SaaS account.

Security On-path scanners

Deterministic detection for secrets, PII, injection phrasing, jailbreak phrasing, and system-prompt leaks. No extra judge model required.

Five-minute start

Install locally, run the mock model, and open the web app. No API key required.

# Clone the repo
git clone https://github.com/cosen-ai/cosen.git
cd cosen

# Install and run
python -m pip install -e .
cosen init
cosen demo
cosen serve --mock  # http://127.0.0.1:8080/

Why Cosen

Built for teams that ship AI products, not another agent framework.

  • Model-agnostic — OpenAI-compatible + Anthropic adapters, no vendor SDK lock-in.
  • Local-first — SQLite on disk, no ClickHouse, no cloud account.
  • Deterministic security — block or redact on the request path.
  • Product attribution — tag every call with project, feature, user, session.
  • Open source — Apache-2.0, self-hostable, with optional Cloud/EE later.
# Point your OpenAI SDK at Cosen
from openai import OpenAI

client = OpenAI(
  base_url="http://127.0.0.1:8080/v1",
  api_key="not-needed-in-mock"
)

client.chat.completions.create(
  model="gpt-4o-mini",
  messages=[{"role": "user", "content": "hello"}],
  extra_headers={
    "X-COS-Feature": "support-bot",
    "X-COS-Project": "acme"
  }
)
// Add to Cursor MCP settings
{
  "mcpServers": {
    "cosen": {
      "command": "cosen",
      "args": ["mcp"]
    }
  }
}

Works inside Cursor

Add Cosen as an MCP server and let Cursor scan prompts, estimate costs, read local reports, and route chat calls through the gateway.

  • Security scan — check prompts and outputs for secrets or injection.
  • Cost estimate — model + tokens = USD before you run.
  • Local report — ask Cursor to summarize spend and findings.
  • Gateway chat — talk to any connected provider through Cosen.

Works with LLM CLI agents
